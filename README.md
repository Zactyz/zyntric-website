# Zyntric Website

A modern, responsive website for Zyntric, a company that builds custom wealth tech tools for financial advisors.

## Project Overview

This website showcases Zyntric's services focused on:
- Creating custom wealth tech solutions for financial advisors
- Delivering mobile-first tools that enhance client experience
- Offering branded financial tools that advisors can use with their clients

The site is built with:
- HTML5
- CSS3 (with CSS variables, flexbox, grid layouts, and animations)
- Vanilla JavaScript (no frameworks)
- Responsive design (mobile-first approach)

## Features

- Modern, fintech-focused design with teal/coral colorway and directional elements
- Dark mode support with automatic preference detection and toggle
- Mobile-responsive layout with hamburger menu on smaller screens
- Interactive device mockup carousel in hero section
- Smooth scrolling navigation
- Animated elements that appear on scroll
- Interactive process timeline
- Testimonial showcase
- Email subscription form with validation
- Accessible design with WCAG AA compliance

## Brand Guidelines

The website follows a comprehensive brand system outlined in [brand-guidelines.md](./brand-guidelines.md) including:

- **Logo**: Dynamic, geometric Z with directional arrows representing financial movement
- **Color Palette**: Teal (#008D91) primary color with coral (#FF6B6B) accent for contrast
- **Typography**: Space Grotesk for headings and Inter for body text
- **UI Components**: Consistent design language with diagonal cutouts matching the logo
- **Dark Mode**: Full dark mode support with appropriate color adaptations

## Design Decisions

- **Logo Design**: The Z incorporates upward and downward arrows symbolizing financial flow, with a vertical stroke creating a dollar sign effect
- **Color Scheme**: Teal primary with coral accent creates a modern, trustworthy fintech aesthetic
- **Typography**: Space Grotesk (headings) and Inter (body) maintain a geometric, modern look
- **Layout**: Card-based design with angular corners and clear visual hierarchy
- **Visual Motif**: Diagonal cutouts in UI elements echo the arrows in the logo
- **Accessibility**: High contrast text, descriptive alt tags, semantic HTML, and ARIA attributes
