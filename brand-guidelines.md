# Zyntric Brand Guidelines

## Logo
The Zyntric logo features a dynamic, geometric Z shape framed by directional arrows, symbolizing financial movement and growth. The upper teal arrow points upward, representing growth and positive returns, while the lower coral arrow points downward, conveying balanced financial flow. A vertical stroke intersects the Z, creating a subtle dollar sign effect that reinforces the fintech nature of the brand.

### Logo Anatomy
- **Upper Arrow**: Teal upward arrow representing growth and positive financial momentum
- **Z Shape**: Bold, stylized Z in teal, the primary brand identifier 
- **Lower Arrow**: Coral downward arrow balancing the design and suggesting holistic financial management
- **Vertical Stroke**: Teal vertical line creating a dollar sign effect, reinforcing financial services
- **Wordmark**: Strong, uppercase "ZYNTRIC" in the primary teal

### Logo Versions
- **Primary Logo**: Full color logo on light background
- **Dark Mode Logo**: Full color logo optimized for dark backgrounds, with brighter teal and coral
- **Monochrome**: Single color version for embossing or restricted color usage

### Logo Usage Guidelines
- Maintain clear space around the logo equal to the height of the "Z" icon
- Do not distort, rotate, or alter the color of the logo
- Do not separate the arrows from the Z except in approved icon-only applications
- Minimum size for legibility: 24px height for digital, 0.25" for print

## Color Palette

### Primary Colors
- **Zyntric Teal** (#008D91): Signature teal color, used for primary branding elements and the main logo
- **Deep Teal** (#005E62): Darker shade for hover/active states and dark mode

### Accent Colors
- **Coral** (#FF6B6B): Warm highlight for CTAs, the lower arrow, and infographics (used sparingly)
- **Soft Orange** (#F38C50): Secondary accent for graphs, tooltips, empty-states

### Status Colors
- **Info** (#4379FF): Clear blue for informational elements
- **Success** (#3EB991): Green for success states and confirmations
- **Warning** (#FFB84D): Amber yellow for caution states
- **Error** (#E01563): Bright red for errors and alerts

### Neutral Colors
- **White** (#FFFFFF): Pure white for backgrounds and text on dark surfaces
- **Light Gray** (#F9FAFB): Subtle background for cards and sections
- **Medium Gray** (#E5E8EB): Borders and dividers
- **Neutral Gray** (#A0A4A8): Disabled text and secondary content
- **Dark Gray** (#2E2E2E): Primary body text
- **Charcoal** (#1A1A1A): Dark mode backgrounds

### Gradients
- **Primary Gradient**: `linear-gradient(135deg, #008D91 0%, #4379FF 100%)`
  - Used for hero elements, CTAs and visual highlights

## Typography

### Font Families
- **Headings**: Space Grotesk (geometric sans-serif)
- **Body**: Inter (clean, modern sans-serif)

### Font Weights
- **Regular**: 400 (body text)
- **Medium**: 500 (emphasis, subheadings)
- **Semibold**: 600 (buttons, important UI elements)
- **Bold**: 700 (headlines, strong emphasis)

### Type Scale
- H1: `clamp(2.5rem, 5vw, 3.75rem)`
- H2: `clamp(2rem, 4vw, 2.5rem)`
- H3: `clamp(1.25rem, 3vw, 1.5rem)`
- Body: `1rem` (16px)
- Small: `0.875rem` (14px)

## UI Elements

### Buttons
- **Primary Button**: Gradient background with white text
- **Secondary Button**: Transparent with teal border and text
- **Large Button**: Increased padding for primary CTAs
- **Icon Button**: Square or circular, uses icon only

### Containers
- **Border Radius**: 8px (small), 12px (medium), 20px (large)
- **Box Shadows**:
  - Small: `0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)`
  - Medium: `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)`
  - Large: `0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 10px 10px -5px rgba(0, 0, 0, 0.04)`

### Form Elements
- Text fields use 8px border radius
- Checkboxes and radios use custom styling with primary color
- Dropdowns have light background and teal highlight

## Dark Mode
When in dark mode:
- Background shifts to charcoal (#1A1A1A)
- Text becomes off-white
- Primary teal brightens to #00B3B8 for better contrast
- Coral accent brightens to #FF8378
- UI elements receive darker backgrounds and appropriate contrast adjustments

## Accessibility
- All color combinations meet WCAG AA standards (4.5:1 for normal text)
- Interactive elements have :focus states with visible outlines
- Text maintains minimum size of 16px for body content
- Contrast is carefully maintained in both light and dark modes

## Animation & Transitions
- Subtle transitions for interactive elements: 0.3s ease
- Quick transitions for immediate feedback: 0.2s ease 
- Scroll animations fade in with subtle vertical movement
- Hover effects include slight scaling or elevation change

## Website Design System
The website follows a consistent visual language with these key components:
- Card-based layout for content organization
- Consistent vertical rhythm with 4px base grid
- Section spacing using multiples of 1rem (16px)
- Responsive design with mobile-first approach
- Clean, minimalist UI with focused content hierarchy
